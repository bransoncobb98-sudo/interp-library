# Not used

`pace.json` (a placeholder reading pace) and `league_limits.json` (TFA, NSDA and UIL time limits from
secondary sources) were used in Phase 4 to estimate run times and flag them against league limits.
On 2026-09-30 the director chose to skip run-time estimates and league rules entirely, so nothing reads
these files any more. They are kept for the record. Nothing in the library states or implies a run time.
